## 自动化测试脚本示例

### DEBUG广播测试脚本
```bash
# 发送单条消息
adb shell am broadcast -a ai.openclaw.android.DEBUG_SEND_MESSAGE --es message "你好"

# 批量发送测试
for i in {1..5}; do
  adb shell am broadcast -a ai.openclaw.android.DEBUG_SEND_MESSAGE --es message "测试消息 $i"
  sleep 2
done
```

### 通用测试检查点
- 所有P0测试用例必须通过才能发布
- P1测试用例建议通过，影响用户体验
- P2测试用例可选，提升产品质量
- 自动化测试优先执行，提高效率
- 手动测试关注用户体验和界面细节
